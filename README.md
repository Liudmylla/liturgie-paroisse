# Литургия по QR-коду / La Liturgie par QR code

Сайт для прихода Вселенского патриархата во Франции. Человек сканирует QR-код в храме, и на телефоне открывается воскресная литургия свт. Иоанна Златоуста: церковнославянский текст русскими буквами и французский перевод, в две колонки или по одному языку.

Сайт сам считает церковный день по новоюлианскому календарю (неподвижные праздники — по гражданским датам, Пасха — православная) и подставляет:

- воскресный глас;
- тропарь и кондак гласа, кондак «Предстательство христиан»;
- прокимен и аллилуиарий гласа;
- Апостол и Евангелие дня целиком: славянский текст Елизаветинской Библии и французский перевод Луи Сегона (1910).

Изменяемые части выделены цветом. Есть крупный шрифт, тёмная тема и кнопка «PDF» (печать или сохранение в PDF).

## Как открыть

- Сайт: <https://liudmylla.github.io/liturgie-paroisse/> — всегда открывается ближайшее воскресенье.
- Конкретная дата: `?date=2026-12-06`, например <https://liudmylla.github.io/liturgie-paroisse/?date=2026-12-06>.
- Плакат с QR-кодом для печати: `qr/affiche.html` (открыть в браузере и напечатать на A4).

### Включить сайт (один раз)

На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**. Через минуту-две сайт появится по адресу выше.

## Что пока надо проверять вручную

Полностью автоматически собираются **обычные воскресенья по Пятидесятнице** — это большая часть года. Для особых дней (двунадесятые праздники, воскресенья Триоди и Цветной Триоди, праотцев, отцев, по Рождестве и т. п.) сайт показывает название дня и чтения, но предупреждает жёлтой плашкой, что песнопения праздника надо добавить.

Добавки делаются в файле `data/overrides.js` — по дате, прямо в браузере на GitHub (значок карандаша). Пример с тропарём святого есть в самом файле.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `data/config.js` | Название прихода, адрес сайта, имена Патриарха и митрополита, тропарь храма |
| `data/overrides.js` | Добавки на конкретные воскресенья |
| `data/liturgy.js` | Неизменяемый текст литургии (славянский + французский) |
| `data/octoechos.js` | Воскресные тропари, кондаки, прокимны и аллилуиарии 8 гласов |
| `data/bible/` | Новый Завет: `cs` — Елизаветинская Библия, `fr` — Сегон 1910 |
| `js/calendar.js` | Пасхалия, глас, неделя по Пятидесятнице |
| `js/readings.js` | Таблицы воскресных чтений |
| `js/app.js` | Сборка службы и показ на экране |

## Проверка текстов

- Славянские песнопения набраны по памяти по Октоиху и Служебнику — **регенту нужно сверить** с книгами клироса.
- Французский перевод литургии и песнопений — **рабочий**, сделан для понимания, а не для пения. Его стоит отдать на вычитку франкоговорящему прихожанину или заменить на перевод, принятый в Митрополии Франции (с разрешения правообладателя).
- Чтения: в начало добавлено «Братие» / «Во время оно», но зачальные слова Евангелия в Служебном Евангелии иногда немного отличаются от библейского текста.
- Осенняя «лукинская преступка» (греческий порядок чтений) выключена: `lukanJump: false` в `data/config.js`. Уточните у настоятеля, какому порядку чтений следует приход.

## Запуск на своём компьютере

```bash
npm start          # http://localhost:8000
npm install && npm run qr   # заново создать QR-код, если поменялся адрес сайта
```

Источники текстов Библии: [getbible.net](https://getbible.net) (Church Slavonic Elizabeth Bible, Louis Segond 1910 — общественное достояние).
